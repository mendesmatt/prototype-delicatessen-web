# Delicatessen — E-commerce App

> Interactive e-commerce app prototype for artisanal food shops, featuring category browsing, certified-origin labels and a live shopping bag.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Specialty food retail

Interactive e-commerce app prototype for artisanal food shops, featuring category browsing, certified-origin labels and a live shopping bag.

**Highlights**

- Product shelf filtered by category
- Certified-origin badges on featured items
- Live shopping bag with running total

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
